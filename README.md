# 🩺 MedTech Academy

## 📌 About The Project (عن المشروع)
**MedTech Academy** is an advanced, interactive web-based platform tailored for students. It acts as a comprehensive exam simulator, preparing students for critical Mid-Course and Final Ministerial examinations through a highly structured and smart Quiz Engine.

منصة تفاعلية ذكية، مصممة هندسياً لمحاكاة الامتحانات الجامعية والوزارية بطريقة احترافية. توفر المنصة بيئة اختبار متقدمة خالية من التشتت، مع محرك أسئلة ذكي يدعم خلط البيانات عشوائياً وتقييم الأداء فورياً.

## ✨ Key Features (المميزات الرئيسية)
*   **🧠 Smart Quiz Engine:** Built with Vanilla JavaScript to randomly shuffle questions and options on every attempt.
*   **📚 Sectioned Learning:** Dedicated test modules for specific lectures (e.g., Pediatrics, Geriatrics, Obese Patients, Thoracic, Urological).
*   **🎯 Ministerial Simulation Mode (الوزاري الشامل):** A combined pool of high-yield questions mimicking the exact environment of the final exams.
*   **⚠️ EXCEPT & SBA Logic:** Specially designed question formats to train students on tricky "All are true EXCEPT" and "Single Best Answer" clinical scenarios.
*   **⚡ Instant Feedback & Rationale:** Immediate display of correct answers along with detailed scientific explanations after each choice.
*   **📱 Responsive & Modern UI:** Fully styled with Tailwind CSS, ensuring a seamless experience across mobile and desktop devices.

## 🛠️ Built With (التقنيات المستخدمة)
*   HTML5
*   Tailwind CSS (via CDN)
*   Vanilla JavaScript
*   FontAwesome (Icons)

## 🎓 Target Audience
Students, specifically university students in any medical department.
